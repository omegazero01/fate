# Goals 与执行约束对齐 SERIES：实施及验收

日期：2026-11-02。代码基线 `25d164cc`；功能快照 `691648bb`。已按用户确认暂停旧运行任务并发布。

## 实际改动与兼容

- 新任务使用 `series-single-session-v1`：同一个原生 pi 会话依次保存约束、资产和目标，仅装配已启用的三个 Goals 工具，不装配 MCP、Skill 或文件工具。目标栏仍是最终验收结果的唯一来源。
- 旧 `goal-field-isolation-v1` 未完成初始化继续双阶段恢复；已完成任务不重拆、不改写。新增策略在创建任务时明确保存，数据库默认值保留旧策略用于兼容。
- 约束正文保存整理后的 `text`，引用另存 `source.quote`、来源字段、原文哈希及上下文。撤掉整段逐字正文限制，保留原文条件、否定与例外；不从 URL 自行创建排他范围。
- 修复实测发现的字段错误：`groundConstraint` 原先返回 `text: quote`，把已拆开的正文覆盖成整段引用，产生重复约束并丢失明确指代。新增落库断言覆盖此问题。
- 原生参数校验、领域保存及进行中保存均有持久错误回执。错误未解决时不能提交目标或触发原文兜底；同批提前调用 `set_goals` 被拒绝。正常无目标产出才兜底为目标栏原文。暂停、取消、禁用或归属失效不放行。
- Planner、Worker 每次原生请求重新读取约束；工具执行前核对约束版本。版本变化时阻止过期模型批次启动新目标操作，保留只读查询与已有事实写回。记录上下文采用的版本；不修改 pi 循环、Worker 配额或派单唤醒。
- Worker 宿主约定明确：当前唯一意图、约束优先、纠偏不能增加其他方向，完成或受阻后写回退出。
- 精确匹配旧内置模板时升级；自定义提示词及历史版本保留，提供未启用修订候选。预览展示新任务实际单会话工具集合。
- 界面显示“允许／限定”“限制／注意事项”，原文可展开，缺失来源明确显示“来源未记录”。390px 下标题和正文分行，避免长标签挤压内容。

参考：[SERIES Goals](https://github.com/neouks/series/blob/main/agent/goals.go)、[约束约定](https://github.com/neouks/series/blob/main/agent/constraints.go)、[原文兜底](https://github.com/neouks/series/blob/main/server/goals.go)。本次沿用其单会话顺序及职责约定，没有照搬已退役的资产审批。

## 真实 DeepSeek 与局限

全部使用本地合成资料，外部测试目标请求为零。凭据仅从受保护本地备份进入隔离库，验收后清空测试配置密钥并删除临时凭据源库；不提交凭据。

累计 67 次模型请求（包含失败及被后续审查取代的验收运行）。最终完整行为运行 20 次请求，结果如下：

- “资产测试覆盖度100%”加复杂背景只形成一个目标。
- 两个独立交付结果形成两个目标；“无需重点关注 XSS，除非……”保留语气与例外。
- 唯一明确的当前目标补充具体地址，原文引用保持原样。
- 自动任务：Goals → Planner → 一条 Worker 意图 → 一条实际事实 → Planner 证明目标 → `done`；无重复派单。
- 附加 Worker：原生 steering 要求读取另一份资料，但它只调用当前文件的 `read` 和 `record_fact`，未读取禁止的其他文件，正常完成。此为具体样本行为证据，不是任意自然语言指令的形式化保证。

首次 18 次运行的断言过弱，未识别正文覆盖缺陷，不能视为最终语义通过。随后两次分别因过严的指代断言、真实缺失指代而失败；修复字段保存、加强明确指代提示和断言后，18 次及最终20次运行通过。每次结果和失败原因均保留在 [验收摘要](evidence/goals-series-20261102/acceptance.json)。完整请求与日志保存在受保护的本地验收目录，摘要含日志哈希。

尚未核实用户截图中七条历史约束及具体违规动作；按已确认范围未重放该任务。来源匹配只证明引用来自用户输入，不能证明整理后的语义完全等价。模糊指代、任意自然语言冲突仍依赖模型理解，未新增语义审核模型或规则引擎。
