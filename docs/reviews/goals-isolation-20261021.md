# Goals 目标栏分阶段隔离：实施与验收

最终核对日期：2026-10-23（Asia/Shanghai）。隔离测试与真实模型资料生成于 2026-10-21；末轮构建及发布核对于 2026-10-23 完成。

## 实施结果

新任务先通过 Goals 提取原文约束与目标资产，再创建独立 pi 会话，仅根据目标栏保存目标。描述中的架构分析、接口梳理、漏洞挖掘不再成为额外验收目标。Planner 仍能从任务黑板读取描述背景。

参考 [SERIES agent/goals.go](https://github.com/neouks/series/blob/main/agent/goals.go) 的“先约束、后目标”顺序；该实现仍在同一模型输入中提供目标与描述。本次按确认方案将两阶段会话、工具和恢复状态隔离。[SERIES server/goals.go](https://github.com/neouks/series/blob/main/server/goals.go) 的目标初始化后再启动引擎及原目标兜底思路保留，约束提取失败则暂停，不跳过。

| 能力 | 实际实现与边界 |
|---|---|
| 目标必填 | HTTP `/api/tasks` 与 Auto `spawn_task` 统一检查非空字符串，拒绝时返回 `TASK_GOAL_REQUIRED`，不创建任务或调用模型 |
| 阶段一 | 接收目标与描述；仅已启用的 `set_constraints/register_user_target`；原文约束校验及资产登记语义沿用现有实现 |
| 阶段二 | 新建独立原生 pi 会话；用户消息只有目标栏，描述模板变量置空；仅 `set_goals`，无文件、查询、MCP、Skill 或其他会话历史 |
| 来源 | 每个新 Goals 目标保存 `field/quote/source_hash/version/fallback`；引用必须是本次目标快照的原文子串 |
| 幂等与恢复 | `goals_bootstrap` 记录输入快照、阶段和已提交目标；目标节点与完成凭据同事务提交；重复执行不重复拆解、覆盖或发模型请求 |
| 失败 | 约束失败暂停；目标失败可回退为原目标单节点；取消、暂停、租约失效、角色或目标写入工具禁用不触发回退 |
| 启动顺序 | 两阶段完成后再启动 Planner/Worker；已有种子意图也受此门控 |
| 历史兼容 | 只有新公共创建入口登记新策略；既有任务不回填、不重写；Main 追加目标接口维持原参数 |
| 提示词 | 精确匹配已发布内置文本才启用新版；自定义文本继续生效，另存未启用候选；保留全部历史版本 |
| 页面 | 创建页解释描述与目标的用途；Goals 预览列出两阶段限制；目标与规划过程区显示阶段状态和实际调用 |

实现集中于 `src/agent/roles.ts`、`src/db/goals-bootstrap.ts`、`src/tools/goals.ts`、`src/engine/engine.ts`、`src/agent/goals-policy.ts`、`src/agent/goals-migration.ts` 及对应 HTTP/Auto 创建入口。

## 最终 REVIEW 与限制

已复核公共创建、准入、两阶段装配、写入事务、取消及恢复、提示词迁移和过程统计链路；本次范围内未发现未关闭的 P1/P2。

`source_quote` 校验只能证明引用来自目标栏，不能证明模型完全理解语义。防止扩展目标依靠独立输入、严格工具集合和行为回归；自定义提示词文字本身可能带有用户主动写入的背景，平台不会擅自改写。仅新的公共创建任务采用新策略，底层存储导入及历史任务不自动迁移。

本次真实模型仅覆盖两个合成案例；强杀、失败、取消等异常由确定性原生 pi 回归覆盖，不能称为所有异常均经过真实供应商测试。
