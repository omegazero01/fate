# Worker 写回结果表格验收

Worker 结束后的资产、事实和漏洞现在由平台按真实持久记录生成三列表格。长总结默认折叠，记录详情和完整原文仍可读取、复制。已在隔离资料和当前 5173 的历史任务上核对，不新增模型整理请求，不改变 Worker 写回时机、工具能力或 Planner 调度。

## 数据口径与接口

- `GET /api/tasks/:id/turns/:turnID/writebacks`：只读；支持 `bucket=current|previous`、`cursor`、`limit`（默认 20，最大 100）。响应包括完整计数、记录类型、编号、摘要、来源回合、详情引用和下一页游标。游标绑定任务、回合、分区及活动版本。
- `TurnSummary.writebacks` 为可选展示字段，现有摘要通知继续复用，没有新增 SSE 订阅。
- 资产依据 `asset_tool_writes` 的成功凭据；事实、漏洞依据意图来源、图边和原生工具调用标识。模型文字中的编号、意图已有资产锚点、失败批次项均不作为写入证明。重复调用按首次持久调用归属，不重复计入恢复回合。
- 本轮与此前执行分别查询；计数不受聊天活动分页或 40 条停止引用限制。旧来源无法准确关联时显示不完整提示，不把读取失败当成零条。
- 资产统一标为“已登记”。负面观察、推断和实测采用不同说明；未提交漏洞报告不等于证明没有漏洞。记录详情展示当前保存内容，不宣称是不可变的历史快照。

## 界面与提示词

窄侧栏、放大面板共用三列表格。点击编号展开真实资产或图记录详情；图节点和漏洞提供跳转入口。完整原文保留，不解析或改写旧总结中的线索与测试影响。中断、停止及预算耗尽显示“已保存的部分结果”。

Worker 继续边发现边写回。新增简短约定要求 `summary` 使用通俗结论，细节及影响放在 `detail/evidence`，最终说明不重复平台表格。仅精确匹配已发布内置模板时自动升级并保留版本；自定义模板正文、回退版本继续有效，可查看新版候选。宿主约定不会在默认正文和协议中重复注入。
