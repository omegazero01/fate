# Retester 移除与工具精简复审（2026-10-20）

## 结论与验收边界

Retester 执行入口已退役，历史记录保留只读。七类角色继续使用 pi 原生模型循环、工具循环、会话持久化、压缩与工具搜索。核心写回工具常驻，低频内置工具按需发现。

本轮基于开始时的实际工作区增量实现，保留审批移除、资产查询及 Planner 上下文等已有未提交改动。测试、构建和发布对象是这份完整工作区；本报告不把仅检出新提交的干净 HEAD 当作已验证版本。尤其资产合并入口沿用工作区已有 `asset_search/asset_get` 实现。

**真实模型成本验收尚未通过。** DeepSeek 18 个对照条件请求均返回 HTTP 402 `Insufficient Balance`，未产生成功模型响应或有效 usage；不能据此声称实际 Token、缓存命中率或完整任务费用降低。已保留失败账本，并将对照脚本改为认证、额度错误立即停止。

## 工具清单与兼容

对原有 80 个系统条目的核实结果：40 个当前实现、10 个兼容入口、28 个无当前实现、2 个 Retester 专属退役工具。原先待核实的 29 项中，`tool_search` 已接入原生实现，因此无实现条目为 28 项。完整名称见 [目录核实数据](evidence/tool-slimming-20261020/catalog-classification.json)。初始化新增的缺失条目与这份“原 80 项”统计分开，不删除原配置。

| 原入口 | 新入口 | 兼容约束 |
|---|---|---|
| 节点、事实、过程索引与冷图读取 | `context_search/context_get` | 保留旧会话及自定义提示词/Skill 明确引用的旧名称；仍须原角色有绑定且未禁用 |
| `read_tool_output`、`read_attachment`、`traffic_body` | `context_get` | `output:`、`attachment:`、`traffic:` 引用；沿用各子能力的旧禁用开关 |
| `list_assets`、`list_untested_assets` | `asset_search` | 空 DSL 列表与未测试筛选继续使用原查询语义；详情为 `asset_get` |
| 文件与单次命令 | pi `read/bash/write/edit` | 不改变现有角色绑定 |
| 交互终端 | `shell_*` | 低频按需加载，句柄仍只属于当前执行 |
| 新资产 Schema | `insert_assets.assets` | 新会话只声明 `assets`；旧 `items` 适配仍可执行，旧会话/明确引用保留兼容 Schema |

读取引用返回 `next_item/next_offset` 等续读信息。工具输出与附件保持原 UTF-16 字符偏移；流量正文按字节偏移并提供无损编码，不能混用单位。批量响应保持完整 JSON，并受 20 KiB 上限约束；大结果沿用持久原文引用。跨任务读取、缺口记录、引用版本及来源任务只读限制保留。

实际执行前仍检查最新绑定。合并入口不能绕过旧子能力禁用设置；恢复会话也不能恢复已撤销能力。Retester 不适用旧会话可执行兼容。

内部工具搜索独立于 MCP；MCP 连接失败时内部发现仍可用，并报告外部发现未完成。中文空匹配提示使用英文工具名或关键词。核心读取、事实和漏洞写回无需先搜索。自定义工具直接装配，用户提示词和 Skill 不被重写。

## 回归与复审

专项覆盖：

- 退役接口、旧会话只读、触发器不复活、迁移幂等、有效旧租约阻止提前释放，历史结论和漏洞状态保留。
- 七类角色装配、原生工具 Schema、直接回退、自定义旧名称与参数、最新禁用开关。
- 原生 pi 搜索、发现后调用、重启恢复已加载集合、不重放写入、撤销能力、中文提示、MCP 断线。
- 工具输出/附件/流量分页和 UTF 边界、完整 JSON、跨任务访问拒绝、旧资产开关。
- 既有 Worker 增量写回、自然结束、Planner 补位、重复意图、冷图、来源任务与强杀恢复回归。

最终复审发现并修复：退役会话仍可经通用删除接口删除；旧会话引用的只读工具未进入兼容候选；预览与运行原生 bash 描述不完全一致。终端测试中固定 80/250 ms 等待导致构建负载下偶发失败，已改为等待实际就绪/缓冲区状态，并在失败时清理进程；未改变生产终端静默等待语义。

服务端全量 57 个文件、535 项通过，1 项跳过；前端专项 64 项通过。前后端类型检查、后端编译、Next 普通与静态构建通过。具体结果与发布核验见 [validation.json](evidence/tool-slimming-20261020/validation.json) 和 [deployment.json](evidence/tool-slimming-20261020/deployment.json)。一项依赖隔离环境真实 LLM profile 的接口测试跳过，未计入通过。

浏览器在隔离环境检查了工具分类、真实参数只读、七角色装配预览、历史漏洞复测及退役会话；覆盖当前窄屏视口和明暗主题。未声称本轮重新覆盖整站全部响应式尺寸。截图：[历史复测](evidence/tool-slimming-20261020/history-readonly.png)、[退役会话](evidence/tool-slimming-20261020/retired-chat-dark.png)。
